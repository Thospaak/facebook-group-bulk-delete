# Facebook Group Bulk Delete Script

สคริปต์ JavaScript สำหรับผู้ดูแลกลุ่ม (Admin) เพื่อช่วยลบโพสต์เก่าๆ ใน Facebook Group โดยอัตโนมัติ

## ⚠️ คำเตือน (Disclaimer)
- การใช้สคริปต์นี้อาจมีความเสี่ยงที่บัญชีจะถูกระงับชั่วคราว (Action Blocked) หากใช้งานถี่เกินไป
- ผู้พัฒนาไม่รับผิดชอบต่อความเสียหายใดๆ ที่อาจเกิดขึ้นกับบัญชี Facebook ของท่าน
- **ควรสำรองข้อมูลสำคัญก่อนใช้งาน**

## 🛠 วิธีใช้งาน

1. เปิดหน้า **Facebook Group** ที่ต้องการลบโพสต์ (แนะนำให้ใช้ผ่าน Chrome บน Desktop)
2. กดปุ่ม `F12` หรือคลิกขวาแล้วเลือก `Inspect` (ตรวจสอบ)
3. ไปที่แท็บ **Console**
4. พิมพ์คำว่า `allow pasting` แล้วกด Enter (เพื่อปลดล็อกการวางโค้ด)
5. คัดลอกโค้ดจากไฟล์ `script.js` ในหน้านี้ ไปวางใน Console
6. กด **Enter** เพื่อเริ่มทำงาน

## ⚙️ การทำงานของสคริปต์
- สคริปต์จะค้นหาปุ่มเมนู (...) ของโพสต์
- กดเลือก "ลบโพสต์"
- กดยืนยันใน Popup
- **หน่วงเวลา 3 วินาที** ก่อนเริ่มลบโพสต์ถัดไป (เพื่อความปลอดภัย)
- หากโพสต์หมดหน้าจอ จะทำการเลื่อน (Auto Scroll) เพื่อโหลดโพสต์ใหม่ให้เอง
